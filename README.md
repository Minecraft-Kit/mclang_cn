## 📖 关于项目

**基岩版中文译名修正**是一个以个人维护为主、欢迎社区参与的Minecraft简体中文语言修正项目。

项目主要修正游戏中的错译、漏译、术语不统一和文本格式问题，同时补充部分未翻译的界面、隐藏文本及新版本内容。除了基岩版游戏本体，也会根据版本需要完善教育版、试玩版和Minecraft编辑器的相关文本。

译名以实际游戏内容为依据，优先参考[**中文Minecraft Wiki**](https://zh.minecraft.wiki/)；当Java版与基岩版的同一内容采用不同译名时，原则上优先使用Java版简体中文译名。完整的翻译与校对规范见[**贡献指南**](CONTRIBUTING.md)。

### 🌐 [**项目网站**](https://kit.minecraft.spectrollay.com/mclang_cn/)

项目网站使用[**OreUI**](https://github.com/Spectrollay-OreUI/OreUI)技术构建。访问和使用项目网站，即代表你已阅读并同意相关使用条款与免责声明。

### 🎮 适用范围

本项目主要面向基于 **基岩引擎**开发的Minecraft游戏版本，包括：

* **基岩版 | 教育版 | 试玩版 | 基岩版编辑器**

不同平台及版本的具体使用方式可能有所不同，请参阅下方的[**安装使用**](#-安装使用)章节。

## 🚀 安装使用

推荐通过`.mcpack`文件导入语言包：

1. 下载与你的游戏版本对应的`.mcpack`文件。
2. 在Windows上双击文件，或在Android、iOS的文件管理器中使用Minecraft打开，等待游戏完成导入。
3. 打开Minecraft，依次进入 **设置 → 通用 → 全局资源 → 我的资源包**，找到 **中文译名修正包**并激活。
4. 将语言包移动至 **已激活资源包**列表的最顶端，确保修正后的文本优先加载。

如果无法直接导入，或需要在特定平台上手动安装，请阅读[**详细安装指南**](INSTALLATION.md)。主机平台与部分特殊版本的安装方式可能受到系统限制。
